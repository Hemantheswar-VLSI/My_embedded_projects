# My Embedded Projects

## About This Repository

This repository contains my embedded systems learning journey, including basic sensor interfacing, IoT projects, Blynk applications, and mini embedded projects developed using Arduino and NodeMCU.

I created this repository mainly to help embedded systems beginners understand practical hardware interfacing and basic embedded programming concepts through simple project examples.

Instead of letting my learning files remain unused, I decided to share them openly so that beginners can learn, experiment, and build upon them.

## How To Use

1. Clone the repository
2. Open the required `.ino` file in Arduino IDE
3. Connect the required hardware modules
4. Upload the code to Arduino / NodeMCU
5. Test and modify according to your requirements
